# Proyecto final

Frontend de la biblioteca, hecho con React y TypeScript. Va a consumir la API REST del curso
(Node + Express) para gestionar libros y socios.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

La app queda en `http://localhost:5173`.

## Estado
